An MCP **server** is a process that advertises capabilities to a client. A server can offer any combination of:

- **Tools** — actions the model can call.
- **Resources** — data the model can read.
- **Prompts** — templates users can invoke.

## Capability negotiation

During initialization, the server declares which primitives it supports:

```json
{
  "capabilities": {
    "tools": {},
    "resources": { "subscribe": true },
    "prompts": {}
  }
}
```

Clients only call methods for capabilities the server advertised.

## Best practices

- Keep each server focused on a single domain (filesystem, GitHub, database, etc.).
- Validate every tool input with a strict JSON schema.
- Return structured errors instead of throwing.
