MCP defines two standard transports. Both carry the same JSON-RPC 2.0 messages.

## stdio

The server is launched as a subprocess; messages are exchanged over `stdin` and `stdout`. Best for local integrations.

```json
{
  "command": "node",
  "args": ["server.js"]
}
```

## Streamable HTTP

The server runs as an HTTP service. The client posts JSON-RPC requests and receives streamed responses via Server-Sent Events. Best for remote or multi-tenant deployments.

```json
{
  "url": "https://mcp.example.com/v1",
  "headers": { "Authorization": "Bearer ..." }
}
```

## Choosing a transport

| Use case | Transport |
| --- | --- |
| Local CLI / desktop tools | stdio |
| Hosted SaaS integration | Streamable HTTP |
| Multi-user services | Streamable HTTP |
