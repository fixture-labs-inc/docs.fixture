The **Model Context Protocol (MCP)** is an open standard for connecting AI assistants to the systems where data lives: content repositories, business tools, and development environments. MCP provides a uniform way for models to discover and use external **tools**, **resources**, and **prompts**.

## Why MCP?

Before MCP, every integration between an AI app and an external system was bespoke. MCP standardizes the wire format and lifecycle so that:

- **Any compatible client** (Claude Desktop, IDEs, custom apps) can talk to **any compatible server**.
- **Servers** expose capabilities once and work across the ecosystem.
- **Users** keep control over what data and actions the model can access.
